# 波形差の解析 — モデル間で iq・トルクの挙動が異なる理由

本ドキュメントは、`bldc-foc-sim` の各モデルで観測される **電流・トルク波形の違い** を、シミュレーション実測値にもとづいて解析する。とくに次の 2 つの比較に注目する。

1. **理想電圧源 (01) と PWM 駆動 (02) の違い** — 定常回転数が変わる
2. **PWM 駆動 (02) とセンサーレス (04) の違い** — 起動時のトルク挙動が変わる

> **数値の前提条件**
> 本ドキュメントの数値は、デフォルトパラメータ・負荷条件 ($i_q^* = 85\,\mathrm{A}$、$T_{load} = 4.3\,\mathrm{Nm}$、$V_{dc} = 48\,\mathrm{V}$) での実測例である。値そのものよりも「どの要因が効くか」という因果関係に注目してほしい。

---

## 1. 理想電圧源モデル (01) vs PWM 駆動モデル (02)

同じ FOC・同じ物理パラメータ ($R = 0.1\,\Omega$、$L = 0.1\,\mathrm{mH}$、$K_e = K_t = 0.0533$、$P_n = 4$) を用いても、両モデルでは **定常回転数が異なる**。原因は PWM 駆動モデル特有の電圧飽和である。

### 1.1 観測される違い

| 量 | 01 理想電圧源 (A 型) | 02 PWM 駆動 (B 型) |
|----|---------------------|---------------------|
| 立ち上がり波形 | — | 01 と一致 |
| $i_q$ 定常値 | 85.00 A (指令到達) | 84.62 A |
| $T_e$ 定常値 | 4.530 Nm | 4.510 Nm |
| $\omega_m$ 定常値 | **144.8 rad/s** | **132.1 rad/s (約 9% 低い)** |

ポイントは次の 2 点である。

- 立ち上がり (過渡) は両モデルで一致する
- 差は主に $\omega$ (最高回転数) に現れる

### 1.2 なぜ立ち上がりは一致し、定常で差が出るのか

立ち上がり過渡では $\omega_m$ がまだ小さく、逆起電力 $K_e \omega_m$ も小さい。このため必要な q 軸電圧が PWM の電圧上限を下回り、両モデルとも PI 出力をそのまま印加できる。結果として $i_q$・$T_e$・$\omega$ の波形は完全に一致する。ところが $\omega_m$ が上昇すると逆起電力が増大し、定常域では PWM 駆動モデルのみが電圧上限に達してクランプされる。理想電圧源モデルには上限がないため $\omega$ はさらに伸び、ここで初めて差が現れる。

### 1.3 原因 — 定常 q 軸電圧バランスと電圧飽和

定常状態の q 軸電圧バランスは次式で与えられる。

$$
v_q = R i_q + K_e \omega_m
$$

逆起電力項 $K_e \omega_m$ は回転数とともに増大し、PWM 駆動モデルでは印加できる相電圧ピークの上限に達する。上限に達すると PI 出力がクランプされ、それ以上 $i_q$ を流せなくなり回転数が頭打ちになる。電圧上限の具体的な算出と落ち着き点の検算は [`pwm-inverter.md`](pwm-inverter.md) §5 にあるため、ここでは重複させない。

> **よくある誤解**
> 「PWM モデルは立ち上がりが直線的なランプになる」という説明は誤りである。実測では立ち上がり波形は理想電圧源モデルと一致し、差は高回転域の電圧飽和という形で現れる。

### 1.4 中点変調による改善

中点変調 (零相注入 / SVPWM 相当) を有効にすると、線間電圧を変えずに相電圧ピークを下げられるため、同じ $V_{dc}$ で基本波振幅を $2/\sqrt{3} \approx 1.155$ 倍まで拡張できる。これにより電圧飽和で頭打ちになっていた回転数が回復し、実測では $\omega_m$ が 132.1 → 144.8 rad/s と理想電圧源モデルの水準まで戻り、$i_q$ も指令値 85.00 A に到達する。中点変調の数式と実装は [`pwm-inverter.md`](pwm-inverter.md) §4・§7 を参照のこと。

## 2. PWM 駆動モデル (02) vs センサーレスモデル (04) — 立ち上がりトルク問題

センサーレスモデルの開発初期、起動シーケンス切り替え時にトルクが乱れる症状があった。原因は 3 つあり、3 つの修正で解決した。

### 2.1 症状

シードあり起動 (真のロータ角を観測器へ注入) から純粋センサーレスへ切り替わる時刻 (`kStartupSteps` 到達時、デフォルト 250 ms) に、次の乱れが発生した。

- $i_d$ が 0 → 約 −23 A に急変
- $T_e$ に段差・振動
- 推定角度誤差の拡大

### 2.2 原因 — 3 要因

**(a) `force_sync` に渡す速度の取り違え**: PLL は電気角を積分するため電気角速度が必要であるが、機械角速度を渡していた。

**(b) ハードな切り替え**: 1 ステップでの不連続切り替えで dq 座標系がジャンプした。推定角がわずかにずれている分だけ座標系が飛び、トルク波形に段差が出る。

**(c) LPF 位相遅れ**: 補償なしでは誘起電圧 LPF による $\arctan(\omega_e/\omega_c)$ の角度誤差が残留する。デフォルト条件 $\omega_e = P_n \omega_m = 4 \times 132 \approx 528\,\mathrm{rad/s}$、$\omega_c = 2000\,\mathrm{rad/s}$ で $\arctan(528/2000) \approx 14.8°$ となる。

### 2.3 修正内容

| 対策 | 内容 |
|------|------|
| 電気角速度の受け渡し | `force_sync` に「機械角速度 × 極対数」を渡す |
| ブレンド遷移 | `kBlendSteps = 200` ステップ (= 50 ms) かけて真値→推定値を線形補間 |
| LPF 位相補償 | `get_angle_deg()` で $+\arctan(\omega_e/\omega_c)$ を加算 |

### 2.4 修正効果

| 指標 | 修正前 | 修正後 |
|------|--------|--------|
| 切り替え時の $i_d$ 急変 | 0 → 約 −23 A (1 ステップで) | なだらかに遷移 |
| 切り替え時の $T_e$ 段差 | 明確な段差・振動 | ほぼ平坦 |
| 定常角度誤差 | 約 12.7° (理論値 14.8° に近い) | 約 −0.5° 〜 −1° |

起動シーケンス (シード注入 → ブレンド遷移 → 自立) の詳細な実装は [`sensorless.md`](sensorless.md) §6 を参照のこと。
