# 用語集

`bldc-foc-sim` および関連ドキュメントで使われる用語をまとめる。

---

## モータ・制御系

| 用語 | 説明 |
|------|------|
| BLDC / PMSM | ブラシレス DC モータ / 永久磁石同期モータ。回転子に永久磁石、固定子にコイルを持つ。 |
| FOC (磁界方向制御) | 固定子電流を磁束方向 (d 軸) とトルク方向 (q 軸) に分解して制御するベクトル制御。 |
| d 軸 / q 軸 | d 軸 = ロータ磁束方向 (トルク非寄与・弱め界磁で使用)、q 軸 = トルクを生む方向。 |
| Clarke 変換 / Park 変換 | Clarke = 三相 UVW → 二相 αβ 固定座標、Park = αβ → dq 回転座標への変換。 |
| 逆起電力 (Back-EMF) | 回転する磁石がコイルに誘起する電圧。`E = Ke·ω`。センサーレス制御の角度推定に利用。 |
| 極対数 (Pole pair) | 回転子の磁極数 ÷ 2。電気角 = 極対数 × 機械角。本コードは 4 (8 極)。 |
| PWM / デューティ比 | パルス幅変調。一定周期のパルスの ON 比率で等価電圧を制御。本コードのキャリアは 40 kHz。 |
| デッドタイム | 三相ブリッジ上下 FET の短絡防止のため挿入する両 OFF 期間。本コードは最大デューティ 95 % で表現。 |
| SVPWM / 中点変調 | 空間ベクトル変調。中性点シフトで線間電圧利用率を 2/√3 倍に拡張する変調方式。 |
| PI 制御 / 極配置 | 比例・積分制御。閉ループを標準二次系 (kWn, kZeta) に一致させてゲインを決める手法。 |
| kWn / kZeta | 自然角周波数 [rad/s] と減衰比 [−]。本コードで設計者が直接調整する 2 変数。 |
| センサーレス制御 | レゾルバ等の角度センサを使わず、誘起電圧やインダクタンスから角度を推定する制御。 |
| オブザーバ / PLL | オブザーバ = 状態推定器、PLL = 位相同期ループ。誘起電圧から角度・速度を推定。 |
| 弱め界磁制御 | 高速回転時に d 軸へ負電流を流し、逆起電力を抑えて高回転域を拡張する制御。 |
| 非干渉制御 (デカップリング) | dq 軸間の結合項 `ωe·L·i` を電圧フィードフォワードで打ち消す制御。 |

## EPS・機能安全系

| 用語 | 説明 |
|------|------|
| EPS (電動パワーステアリング) | モータトルクでドライバの操舵力を補助するシステム。油圧式に対し燃費・整備性で有利。 |
| トルクセンサ / トーションバー | 操舵シャフト中間の捻れる軸。その捻れ角から操舵トルクを検出する。 |
| アシストマップ | センサトルク → モータ電流指令のマップ。ベース + イナーシャ + ダンパ電流で構成。 |
| ベース電流 | 操舵トルク・車速から決まるアシストの基本電流 (V カーブ)。 |
| イナーシャ電流 | 操舵トルクの微分値から決まり、操舵開始時のアシスト立ち上げを補助する電流。 |
| ダンパ電流 | モータ角速度から決まり、ステアリングの外乱・戻り過渡を制動する電流。 |
| ラック推力 | ステアリングラック軸方向の力。タイロッドを介してタイヤに伝わる。 |
| ISO 26262 | 自動車の機能安全規格。電気電子システムの故障による危害を防ぐための要求を規定。 |
| ASIL | 自動車安全度水準。QM < A < B < C < D。S × E × C の組合せで決定。 |
| HARA | ハザード分析・リスクアセスメント。ASIL を決定するための基本的な安全分析プロセス。 |
| S / E / C | シビアリティ (被害規模)、曝露率 (発生頻度)、コントローラビリティ (回避可能性)。 |
| FTTI | 故障耐性時間間隔。故障発生から安全状態に至るまでの許容時間。EPS の例で約 100 ms。 |
| 安全目標 (SG) | ハザードの否定形として記述される最上位の安全要求。FTTI と ASIL を伴う。 |
| FSR / TSR | 機能安全要求 / 技術安全要求。安全目標を段階的に詳細化した要求。 |
| HSR / SSR | ハードウェア安全要求 / ソフトウェア安全要求。TSR を HW/SW 実装レベルへ落とした要求。 |
| ASIL デコンポジション | 高 ASIL 要求を独立した複数要素に分解し、各要素の要求 ASIL を下げる手法。 |

## シミュレーション・コード関連

| 用語 | 説明 |
|------|------|
| プラントモデル | 制御対象の数学モデル。本コードでは `motor_model` がモータのプラントに相当。 |
| 前進オイラー法 | 1 次精度の数値積分法。本コードの電気系の離散化に使用。 |
| 台形積分法 | 2 次精度の数値積分法。本コードの機械系・PI 積分項に使用。 |
| シードあり起動 | センサーレス制御の起動時、一定期間だけ真の角度を観測器に与える方式。 |
| ブレンド遷移 | シード起動から純粋センサーレスへ、推定角を線形補間で滑らかに切り替える処理。 |
| RESULT 行 | シミュレーション終了時に標準出力へ常に出力する、機械可読な定常値の行。 |
